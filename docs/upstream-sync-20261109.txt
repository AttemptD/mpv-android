先同步、验证并推送内核，再将外层 buildscripts/include/depinfo.sh 中

更新差异导出时，在外层根目录执行：
  git -C buildscripts/deps/mpv diff --binary UPSTREAM_SHA HEAD > buildscripts/patches/mpv-upstream-20261109.patch
其中 UPSTREAM_SHA 使用 v_mpv_upstream 的实际值。随后提交并推送外层。
